# ОРЛИЦА — editorial tattoo portfolio

React + Vite. Исходники в `frontend/src`; готовые страницы в корне для GitHub Pages.

## Разработка

`npm ci` → `npm run dev`.

`npm run stage:pages` собирает приложение, экспортирует маршруты и обновляет файлы для публикации. После проверки закоммитьте исходники и сгенерированные страницы. Базовый путь `/Tattoo-/`, переопределяется переменной `SITE_BASE`.

`npm test` проверяет адаптер записи с подменённой сетью, без реальных заявок.

## Контент

Восемь работ отобраны из публичного канала https://t.me/orlica_tatt. Ссылки на оригинальные публикации сохранены в `frontend/src/data.js`. Названия работ — редакционные подписи сайта.

Портреты и пара фото для демонстрации маски взяты из предыдущей версии проекта. Интерактивная маска — визуальная демонстрация, а не документирование результата сеанса.

Числовой прайс не опубликован: источник VK https://vk.ru/sveta_orel_tattoo недоступен для проверки. Перед добавлением сумм нужен актуальный прайс Светы.

## UI и motion

Доступные Radix-примитивы и shadcn-паттерны; адаптированные Magic UI BlurFade/TextAnimate; Aceternity Draggable Card в отдельной сцене. View Transitions для переходов, Motion для движения, Canvas для кисти. Осознанное уменьшение эффектов при prefers-reduced-motion. Изображения WebP с мобильными вариантами. Oswald распространяется по SIL Open Font License.

## Запись

Существующий Supabase endpoint сохранён. При выборе свободного окна заявка отправляется только явной кнопкой. Без даты сайт готовит текст для Telegram; пользователь самостоятельно отправляет его мастеру. Экран черновика не утверждает, что заявка отправлена. Старый административный интерфейс сохранён.

## Проверено

Production build, 15 экспортированных документов маршрутов, 7 изолированных API-проверок. В браузере: фильтр работ, шаги записи, меню, маска рисования; адаптивная композиция на ширине 390 px. Реальный iPhone и частота кадров на устройстве не измерялись.
